## Scope

`apps/api` chứa HTTP adapter, route registration, Swagger và orchestration mỏng. Business rule dài hạn phải nằm trong `packages/domain` hoặc application service riêng.

## Provider Directory Seed Boundary

- Seed demo ProviderDirectory cho cơ sở y tế/FHIR/PACS/LIS phải nằm trong `modules/provider-directory/provider-directory-seed.ts`; `in-memory-provider-directory.repository.ts` chỉ là adapter đọc/ghi mỏng, và `create-provider-directory.repository.ts` phải dùng chung seed đó cho cả PostgreSQL lẫn in-memory. Chạy `pnpm run harness:api-provider-directory-composition` khi đổi các file này.

## Rules

- API public phải nằm dưới `/api/v1`.
- `/health` giữ không version để kiểm tra process/liveness đơn giản; `/ready` dùng cho readiness vì có kiểm tra repository nền tảng.
- Route handler không trả domain object nếu về sau có dữ liệu nhạy cảm; dùng response DTO rõ ràng.
- HTTP API composition phải giữ mỏng: `modules/http/api-routes.ts` chỉ gắn prefix `/api/v1`, system routes và gọi `api-domain-routes.ts`; dependency contract nằm trong `api-route-dependencies.ts`; route wiring theo miền nằm trong `api-identity-routes.ts`, `api-interoperability-routes.ts`, `api-clinical-routes.ts`, `api-medication-routes.ts`, `api-care-workflow-routes.ts`, `api-diagnostic-routes.ts`, `api-document-routes.ts` và `api-audit-routes.ts`. Route hệ thống phải giữ boundary: `system-routes.ts` chỉ làm composition root; `/health` nằm trong `system-health-routes.ts`; `/ready` và kiểm dependency nền tảng nằm trong `system-readiness-routes.ts`; `/runtime`, `/fhir/metadata` nằm trong `system-api-runtime-routes.ts`; chính sách ẩn/hiện runtime diagnostics nằm trong `system-runtime-info.ts`. Chạy `pnpm run harness:api-route-composition` khi đổi các file này.
- API repository composition phải giữ boundary: `api-dependencies.ts` chỉ là barrel công khai; type contract nằm trong `api-repository.types.ts`; close lifecycle nằm trong `api-repository-lifecycle.ts`; factory root nằm trong `api-repository-factory.ts`; repository creation phải tách theo nhóm identity, clinical, medication, care workflow, diagnostic, interoperability và audit trong các file `api-*-repositories.ts`. Chạy `pnpm run harness:api-route-composition` khi đổi các file này.
- Runtime config phải giữ boundary: `runtime-config.ts` chỉ là barrel công khai; đọc env primitive nằm trong `runtime-config-env.ts`; repository mode nằm trong `runtime-config-repository.ts`; public API URL nằm trong `runtime-config-public-api.ts`; body limit/API docs nằm trong `runtime-config-http.ts`; CORS production nằm trong `runtime-config-cors.ts`; record-transfer worker scheduling nằm trong `runtime-config-workers.ts`. Chạy `pnpm run harness:api-route-composition` khi đổi các file này.
- Route ProviderDirectory phải giữ boundary theo module: `provider-directory-routes.ts` chỉ làm composition root; đọc snapshot danh bạ cơ sở y tế nằm trong `provider-directory-query-routes.ts`; export FHIR Bundle/resource nằm trong `provider-directory-fhir-routes.ts`; metadata tổng hợp, lookup resource và OperationOutcome không tìm thấy nằm trong `provider-directory-route-helpers.ts`. Chạy `pnpm run harness:api-route-composition` khi đổi các file này.
- Route xác thực phải giữ boundary theo module: `auth-routes.ts` chỉ làm composition root và quản lý vòng đời rate limiter; login/rate-limit/demo IAM nằm trong `auth-login-routes.ts`; kiểm phiên bearer token nằm trong `auth-session-routes.ts`; audit đăng nhập và hash định danh đăng nhập nằm trong `auth-login-audit.ts`; danh mục tài khoản demo có kiểm soát nằm trong `auth-demo-accounts.ts`.
